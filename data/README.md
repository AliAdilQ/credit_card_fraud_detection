# Synthetic transaction dataset

`sample_transactions.csv` contains **4,000 reproducible synthetic transactions** by default. It contains no real banking, customer, account, or card information. It is generated by this repository and distributed under the project's MIT license; no Kaggle data is redistributed.

```bash
python manage.py generate_dataset --rows 4000 --seed 42
python manage.py train_model
```

The generator in `detection/ml/utils.py` samples a latent fraudulent profile with 4.2% prior probability, legitimate unusual activity, and stealthier fraud. Small random label flips add irreducible noise. Amounts, distances, recent frequency, authentication, and history differ by profile but overlap. Countries and merchant categories are contextual categories, not hard-coded fraud labels. Labels are generated before training; model predictions are never used as ground truth.

| Feature | Meaning / unit |
| --- | --- |
| transaction_datetime | Synthetic UTC date/time; only hour enters the model |
| amount | Purchase amount, USD |
| merchant_category | Retail, Groceries, Dining, Travel, Electronics, Entertainment, Services |
| transaction_type | In-store, Online, ATM, Contactless |
| card_type | Credit, Debit, Prepaid |
| country | US, GB, ID, DE, SG, AU, JP; no nationality or customer identity |
| device_type | Mobile, Desktop, Terminal |
| previous_transactions_count | Number of previous purchases |
| average_transaction_amount | Typical historical purchase amount, USD |
| transaction_frequency | Purchases in the past hour, including this one |
| distance_from_home | Hypothetical distance from home, km |
| distance_from_last_transaction | Hypothetical distance from previous purchase, km |
| ratio_to_median_purchase_price | Purchase amount divided by a hypothetical median |
| used_chip / used_pin_number | Authentication-used flags, 0 or 1; no actual PIN |
| online_order | Online purchase flag, 0 or 1 |
| is_fraud | Synthetic training label: 0 legitimate, 1 fraudulent |

This is a deliberately simplified educational generator. Features such as previous history carry strong synthetic signals, and noise means some transactions cannot be classified from the supplied metadata. Real fraud involves different signals, drift, adversaries, and delayed labels.

The web demo seeds a **separate deterministic dataset** (seed 2026), enriched to roughly 10% synthetic fraud for useful charts. It is scored by the model, so its flagged rate differs from the generator's fraud label rate. Database rows do not contain ground-truth fraud labels.
